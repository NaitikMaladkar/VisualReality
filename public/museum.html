The full collection

Twelve exhibits, no walking required.

Every artifact from the 3D halls, gathered in one place. Tap any card for its animated explanation and sourced stats.

Real science only

Every stat on every plinth is sourced — Bell Labs, IEA, Ember, NREL, Science. If a number is a projection, the label says so. No exhibits were exaggerated in the making of this museum.

Zero WebGL, all CSS

The whole building — floors, walls, glowing plinths, parallax corridors — is CSS perspective, preserve-3d and transforms. If your browser can render a hover effect, it can render this museum.

Made for wandering

Walk with keys, buttons or taps. Prefer a flat floor? The Flat Index shows every exhibit as ordinary scrolling cards. Reduced-motion visitors get an instant, calm version of both.
